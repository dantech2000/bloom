An installed 0.1.4 updates itself: it shows "Restart to update" when the download is ready.

## Interlaced video

Files with interlaced frames, such as DVD rips and TV recordings, showed comb lines on anything that moved. Bloom now puts the fields together by itself, and plays such a file at its full field rate (a 25 fps recording at 50 pictures a second). Every other file is left alone: the filter runs only for frames that a file marks as interlaced.

## Smaller

- The player starts in a virtual machine. It asked macOS for a graphics renderer on a GPU and gave up without one; now it takes what is there. On a Mac nothing changes.

## How this release was made

This is the first release that GitHub Actions built, signed and published. Each push to the repository is now built and tested there, and a release waits for an approval before it is signed. `docs/RELEASING.md` describes it.
