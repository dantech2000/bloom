An installed 0.1.9 updates itself: it shows "Restart to update" when the download is ready.

## Fixed

- **"Play Now" on the Up next card failed with a 404 when the server had replaced the episode.** A server with Sonarr or Radarr swaps a file for a better release while you watch, and the new file is a new item with a new id. Bloom's queue for the Up next card is made when the episode before starts, so it held the old id, and the server answered 404 for it: the player closed with "Could not start playback: HTTP 404". Bloom now notices that the item is gone, asks the server for the episodes of the season, and plays the one with the same season and episode number under its new id. The rest of the queue is rebuilt from it, so the episodes after it play as well. Seen on 2026-10-21 with The Terminal List, season 2, going from episode 1 to episode 2 while the server replaced all eight files of the season.

The same swap makes the server lose the resume point of the episode that is playing (its progress reports fail on the server, which no longer knows the item). That is the server's; the episode starts from the beginning the next time.
