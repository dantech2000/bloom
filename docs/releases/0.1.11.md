## New

- **Image subtitles (PGS, VobSub) no longer force a re-encode or a reload.** When the server transcodes, a PGS or VobSub track used to be burned into the picture: the server re-encoded the video for the subtitle alone, and every switch of the subtitle loaded the item again. Bloom now asks the server for the track as a file, as the Jellyfin web client does, and the player adds it on the side. A switch of the subtitle is instant, the video stays a copy where the bitrate allows it, and "Off" needs no reload either. An image track is fetched when you choose it (a film's PGS tracks are 10 to 60 MB each); the menu says "Loading…" meanwhile. The first request of a film's subtitles still makes the server extract them, which takes some seconds on a large file, as it did for text subtitles.

  A server before Jellyfin 12.2 cannot serve VobSub this way (PGS works on 12.1). When a file does not come, Bloom burns the track in as before, so nothing is lost on an older server.

- **Downloads keep a PGS sidecar.** A `.sup` file beside the media is downloaded with it and plays offline.

## Fixed

- **The subtitle menu could select the wrong track** when one of the subtitle files the server offers did not come: the player numbered the files that came, and the menu counted the ones that were asked for. The menu now goes by the file.
