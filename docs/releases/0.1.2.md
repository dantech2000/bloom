An installed 0.1.1 updates itself: it shows "Restart to update" when the download is ready.

## New

- **Offline server.** When the server does not answer, Bloom says so: a full page at start, an indicator in the top bar during use, and a Retry button. It tries again by itself and reloads the page when the server is back. A proxy that answers for a server that is off (for example Cloudflare's 530) counts as offline.
- **Sharper upscale.** mpv scales the picture to the size of the window. Before, a 1080p file in a larger window was stretched with a simple filter.
- **Debug channel setting** in Settings > About, off by default.

## Safer

- The player verifies the TLS certificate of the server for streams and trailers.
- The settings file is saved through a temp file. A file that cannot be read is kept as `config.json.broken`, so a sign-in is not lost without a trace.
- The access token is no longer in the address of the seek preview images.
- Links that come from the server open only as `http` or `https`.
- Names from the server are checked before they become a path for a download.

## Faster and steadier

- At most 6 images load at once, and an image that failed is tried again.
- The interface redraws about 28 times a second during playback, down from 48.
- mpv closes before the app exits, which removes a crash at quit.
- A crash in the Now Playing artwork is fixed.

## Small

- "Ends at" follows the 12 or 24-hour clock setting of the Mac.
- The time of the last update check shows as "5 minutes ago".
- The app needs macOS 14 or later, as its libraries always did.
