An installed 0.1.7 updates itself: it shows "Restart to update" when the download is ready.

## Fixed

- **The player no longer stands still while the server makes a subtitle.** When the server transcodes a title (for example from outside your network, under the server's bitrate limit for remote clients), its text subtitles come as files, and the server makes each file at the first request, which can take over a minute for a large episode. Bloom asked mpv to fetch the file, and mpv waited for it before it did anything else: the time and the progress bar stayed on the title before, and the Back arrow did not stop the playback. Now the files are fetched beside the player. The title plays at once, Back stops it at once, and the subtitle appears when the server delivers it.
- The address of a subtitle file no longer carries the access key; the player sends it in a header, as for everything else.
