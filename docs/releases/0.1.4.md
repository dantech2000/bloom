An installed 0.1.3 updates itself: it shows "Restart to update" when the download is ready.

## Half the download

The app is 28 MB to download, down from 57 MB, and 58 MB on disk, down from 137 MB.

Bloom carried 91 video libraries, copied from one machine. Most of them were for things Bloom never does: encoding, disc playback, a second graphics stack. Now it carries one library, built from pinned sources by a script in the repository (`dev/build-mpv`), so anyone can build the same thing.

Nothing that plays was taken out: every video and audio decoder, every subtitle format and every filter is still in. Measured against 0.1.3 on the same frames, the picture is the same pixel for pixel, with styled subtitles in Latin, Japanese, Korean and Arabic, and an HDR10 frame within 2 of 255.

One format is gone: tracker music files (`.mod`, `.xm`).

## Fixed

- A video that ends in full screen no longer leaves the library in full screen. The window goes back to how it was before the video started. A window that was full screen before stays full screen, and the next episode of a queue keeps it.

## For developers

- `dev/build-mpv` replaces the copy from the Nix store; a first build takes about three minutes.
- Builds, tests and releases can run on GitHub Actions (`docs/RELEASING.md`).
- The test suite makes no sound.
